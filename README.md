# 🤖 Telegram Video Forwarder & Re-Uploader Bot

একটি শক্তিশালী টেলিগ্রাম বট এবং ইউজারবট — যা দিয়ে যেকোনো চ্যানেল বা গ্রুপ থেকে ভিডিও ফরোয়ার্ড করে কোনো **"Forwarded from"** ট্যাগ ছাড়া সরাসরি আপনার নিজের গ্রুপ বা চ্যানেলে ফ্রেশ আপলোড দিতে পারবেন!

---

## ✨ প্রধান সুবিধাসমূহ (Key Features)

1. **কোনো ফরোয়ার্ড ট্যাগ থাকবে না (Clean Upload)**: ভিডিওটি এমনভাবে আপলোড হবে যেন মনে হবে এটি সরাসরি আপনার গ্রুপে আপলোড করা হয়েছে।
2. **জিরো ব্যান্ডউইথ ও ক্লাউড ফরোয়ার্ড (Lightning Fast)**: ভিডিও আপনার পিসিতে ডাউনলোড করার প্রয়োজন নেই; টেলিগ্রাম ক্লাউড দিয়েই সাথে সাথে (১ সেকেন্ডে) আপলোড হয়ে যায়।
3. **সুরক্ষিত কনটেন্ট সাপোর্ট (Protected Content Fallback)**: যেসব চ্যানেলে "Restrict Saving Content" অন থাকে, সেখান থেকেও স্বয়ংক্রিয়ভাবে ডাউনলোড ও রিলোড করে দেয়।
4. **পোস্ট লিংক সাপোর্ট**: যেকোনো পোস্টের লিংক (যেমন `https://t.me/...`) পাঠালেও ভিডিও খুঁজে আপলোড করে দেয়।
5. **কাস্টম ক্যাপশন ও ওয়াটারমার্ক**:
   - `original`: আসল ক্যাপশন রাখা হবে।
   - `none`: ক্যাপশন ছাড়া একদম ক্লিন ভিডিও আপলোড হবে।
   - `custom`: আপনার পছন্দমতো কাস্টম ক্যাপশন দেওয়া যাবে।
   - `append`: মূল ক্যাপশনের শেষে আপনার গ্রুপ বা চ্যানেলের লিংক/ওয়াটারমার্ক যুক্ত হবে।
6. **সহজ কনফিগারেশন ও উইন্ডোজ ব্যাচ ফাইল**: ডাবল ক্লিক করেই চালু করা যাবে (`run_bot.bat`)।

## 🚀 সেটআপ নির্দেশিকা (Step-by-Step Setup)

### ১. ক্রিডেনশিয়াল সংগ্রহ করুন

1. **API ID & API Hash:**
   - ব্রাউজারে যান: [my.telegram.org](https://my.telegram.org)
   - আপনার ফোন নম্বর দিয়ে লগইন করুন (টেলিগ্রাম অ্যাপে কোড যাবে)।
   - **API development tools**-এ ক্লিক করে যেকোনো নাম দিয়ে অ্যাপ তৈরি করুন।
   - সেখান থেকে `api_id` এবং `api_hash` কপি করুন।

2. **Bot Token:**
   - টেলিগ্রামে যান এবং [@BotFather](https://t.me/BotFather)-কে মেসেজ দিন।
   - লিখুন `/newbot` এবং আপনার বটের নাম ও ইউজারনেম দিন।
   - BotFather আপনাকে একটি **API Token** দেবে।

3. **আপনার গ্রুপের Chat ID:**
   - আপনার বটের ইউজারনেম দিয়ে বটটিকে আপনার গ্রুপে **Add** করুন।
   - বটটিকে গ্রুপে **Admin** বানান (Messages ও Media পারমিশন দিন)।
   - গ্রুপে লিখে পাঠান: `/id` — বটটি আপনার গ্রুপের আইডি দিয়ে দেবে (যেমন: `-1001234567890`)।

---

### ২. `.env` ফাইল কনফিগার করুন

প্রজেক্ট ডিরেক্টরিতে `.env.example` ফাইলের নাম পরিবর্তন করে `.env` রাখুন (বা কপি করুন) এবং আপনার তথ্যগুলো বসান:

```env
API_ID=12345678
API_HASH=your_api_hash_here
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
OWNER_ID=0
TARGET_CHAT_ID=-1001234567890
CAPTION_MODE=original
CUSTOM_CAPTION=Uploaded with ❤️
WATERMARK_TEXT=Join our group: @MyGroup
```

*(নোট: `OWNER_ID` প্রথমে 0 রাখলেও চলবে। প্রথমবার আপনি বটে `/start` দিলে স্বয়ংক্রিয়ভাবে আপনিই বটের মালিক হয়ে যাবেন)*

---

### ৩. বট চালু করুন (Run the Bot)

উইন্ডোজের ক্ষেত্রে:
- সরাসরি **`run_bot.bat`** ফাইলে ডাবল-ক্লিক করুন।
- অথবা কমান্ড প্রম্পট / টার্মিনালে রান করুন:
  ```powershell
  py bot.py
  ```

## 🎮 যেভাবে ব্যবহার করবেন

1. টেলিগ্রামে গিয়ে আপনার তৈরি করা বটের ইনবক্সে `/start` দিন।
2. এখন যেকোনো চ্যানেল বা গ্রুপ থেকে যে ভিডিওটি আপনার গ্রুপে আপলোড দিতে চান, সেটি বটের ইনবক্সে **Forward** করে পাঠিয়ে দিন।
3. **মুহূর্তের মধ্যেই** বট ভিডিওটি আপনার গ্রুপে আপলোড করে দেবে — কোনো ফরওয়ার্ড ট্যাগ ছাড়াই!

### বট কমান্ডসমূহ:
- `/start` : বটের স্ট্যাটাস ও তথ্য দেখাবে
- `/setgroup <ID>` : সরাসরি টার্গেট গ্রুপ পরিবর্তন করুন
- `/mode <original|none|custom|append>` : ক্যাপশন স্টাইল পরিবর্তন
- `/caption <text>` : কাস্টম ক্যাপশন বা ওয়াটারমার্ক টেক্সট সেট করুন
- `/id` : আপনার ও চ্যাটের আইডি দেখুন
- `/help` : সাহায্য নির্দেশিকা

## 🛡️ ইউজারবট মোড (Restricted / Protected Content)

কিছু কিছু চ্যানেলে ফরোয়ার্ড বা সেভ করা ব্লক করা থাকে ("Saving and forwarding not allowed")। সেসব চ্যানেল থেকে ভিডিও নিতে চাইলে:
1. **`run_userbot.bat`** চালু করুন (বা `py userbot.py`)।
2. প্রথমবার আপনার ফোন নম্বর ও টেলিগ্রামে আসা ওটিপি (OTP) কোড দিতে হবে।
3. এরপর যেকোনো ভিডিও আপনার নিজের **Saved Messages**-এ পাঠালেই তা স্বয়ংক্রিয়ভাবে ডাউনলোড হয়ে আপনার টার্গেট গ্রুপে আপলোড হয়ে যাবে!
4. অথবা যেকোনো চ্যাটে লিখুন:
   ```
   .upload https://t.me/c/123456789/100
   ```
